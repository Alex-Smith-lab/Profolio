# Profolio

Professional Career, Portfolio, CV, Resume, Evidence and Planning Workspace.

## Features

- Professional profile
- Skills management
- Work and project history
- Evidence and snapshot uploads
- Professional goals
- Calendar planning
- Financial calculator
- Income and expense tracking
- Portfolio generator
- CV generator
- Resume generator
- PDF export
- PNG export
- Backup and restore
- Dark mode
- Responsive design
- GitHub Pages compatible

## How to use

1. Create a GitHub repository.
2. Add:
   - index.html
   - style.css
   - app.js
   - README.md
3. Commit the files.
4. Open:

Settings → Pages

5. Select:

Deploy from a branch

6. Select:

main / root

7. Save.

GitHub will create the website.

## Data

The current version stores user information in the browser using localStorage.

This means:

- No server is required.
- GitHub Pages can host the application.
- Information remains in the user's browser.
- Backup can be downloaded as JSON.
- Backup can be restored later.
